# 📊 Vendor Performance Dashboard

An end-to-end data analytics project focused on evaluating vendor performance, optimizing procurement decisions, and generating actionable business insights using Python, SQL, and Power BI.

---

## 🚀 Project Overview

This project analyzes vendor-related sales and procurement data to identify:

- Top-performing vendors
- Cost optimization opportunities
- Inventory inefficiencies
- Sales and profit trends
- Vendor contribution to revenue

The dashboard provides interactive visualizations and KPI tracking to support data-driven business decisions.

---

## 🛠️ Tech Stack

- **Python**
- **Pandas**
- **NumPy**
- **SQL**
- **Power BI**
- **Jupyter Notebook**
- **Matplotlib / Seaborn**
